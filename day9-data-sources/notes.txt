Topic: Terraform Data Sources

------------------------------------------------------------
1. Introduction
------------------------------------------------------------

Terraform Data Sources allow us to retrieve information about infrastructure that already exists instead of creating new resources.

A Resource creates infrastructure.

A Data Source reads existing infrastructure.

Data Sources are useful when:
- Existing resources were created manually.
- Infrastructure is managed by another Terraform project.
- Existing cloud resources need to be referenced.
- Existing Docker images, VPCs, Security Groups, etc., need to be used.

Syntax:

data "<PROVIDER_RESOURCE>" "<NAME>" {
    ...
}

Example:

data "docker_image" "nginx" {
    name = "nginx:latest"
}

------------------------------------------------------------
2. Resource vs Data Source
------------------------------------------------------------

Resource
--------
- Creates infrastructure
- Managed by Terraform
- Uses the "resource" block
- Changes infrastructure

Example:

resource "docker_container" "web" {
    ...
}

Data Source
-----------
- Reads existing infrastructure
- Read-only
- Uses the "data" block
- Does not create infrastructure

Example:

data "docker_image" "nginx" {
    name = "nginx:latest"
}

------------------------------------------------------------
3. Provider Configuration
------------------------------------------------------------

Terraform uses providers to communicate with external platforms.

In this project the Docker provider is used.

Example:

terraform {
  required_providers {
    docker = {
      source  = "kreuzwerker/docker"
      version = "~> 3.0"
    }
  }
}

provider "docker" {}

------------------------------------------------------------
4. Reading an Existing Docker Image
------------------------------------------------------------

Instead of downloading or creating an image through a Terraform resource, we retrieve information about an image that already exists.

Example:

data "docker_image" "nginx" {
    name = "nginx:latest"
}

Terraform fetches details like:

- Image Name
- Image ID
- Repository Information

------------------------------------------------------------
5. Using Data Source Values
------------------------------------------------------------

Values returned by a Data Source can be used in other resources.

Example:

resource "docker_container" "web" {

    name  = "day9-nginx"

    image = data.docker_image.nginx.id

    ports {
        internal = 80
        external = 8085
    }
}

Here,

data.docker_image.nginx.id

returns the Image ID of the existing Nginx image.

------------------------------------------------------------
6. Outputs
------------------------------------------------------------

Terraform Outputs display useful information after deployment.

Example:

output "image_name" {
    value = data.docker_image.nginx.name
}

output "image_id" {
    value = data.docker_image.nginx.id
}

output "container_name" {
    value = docker_container.web.name
}

Outputs help users quickly access important resource details.

9. Advantages of Data Sources
------------------------------------------------------------

• Avoids recreating existing infrastructure.

• Improves reusability.

• Makes Terraform configurations modular.

• Useful in multi-team environments.

• Reads infrastructure managed elsewhere.

• Reduces duplication.

12. Interview Questions
------------------------------------------------------------

Q1. What is a Terraform Data Source?

Answer:
A Data Source retrieves information about existing infrastructure without creating or modifying it.

------------------------------------------------------------

Q2. What is the difference between a Resource and a Data Source?

Answer:
A Resource creates infrastructure, whereas a Data Source only reads existing infrastructure.

------------------------------------------------------------

Q3. Why are Data Sources important?

Answer:
They enable Terraform to reuse existing resources, reduce duplication, and integrate with infrastructure managed outside the current configuration.

------------------------------------------------------------

Q4. How do you reference a Data Source attribute?

Answer:

data.<resource_type>.<name>.<attribute>

Example:

data.docker_image.nginx.id

------------------------------------------------------------

Q5. Can a Data Source create infrastructure?

Answer:
No. Data Sources are read-only and cannot create or modify infrastructure.

------------------------------------------------------------
13. Conclusion
------------------------------------------------------------

Terraform Data Sources provide a reliable way to access existing infrastructure and use its information in new configurations. They improve reusability, simplify infrastructure management, and are widely used in production environments where resources already exist. Understanding Data Sources is an essential Terraform skill for building scalable and maintainable Infrastructure as Code (IaC).
