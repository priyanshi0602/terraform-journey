DAY 11 – TERRAFORM TFVARS AND VARIABLE MANAGEMENT

Topic:
Terraform Input Variables, terraform.tfvars and Outputs

---

1. INPUT VARIABLES

---

Terraform variables allow us to pass values into our configuration instead of hardcoding them.

Example:

variable "container_name" {
type = string
}

variable "external_port" {
type = number
}

variable "image_name" {
type = string
}

Variables make Terraform configurations more reusable and easier to modify.

---

2. terraform.tfvars

---

The terraform.tfvars file is used to provide values for Terraform input variables.

For this project:

container_name = "day11-nginx"
external_port  = 8087
image_name     = "nginx:latest"

Terraform automatically loads values from terraform.tfvars when running commands such as terraform plan and terraform apply.

---

3. WHY USE tfvars?

---

Without variables, values would have to be hardcoded directly inside resources.

Using variables and tfvars provides:

* Better reusability
* Cleaner configuration
* Easier customization
* Separation of configuration values from infrastructure code

---

4. TERRAFORM OUTPUTS

---

Outputs display useful information after Terraform creates resources.

This project displays:

container_name = "day11-nginx"
container_port = 8087
image_name     = "nginx:latest"

Outputs can also be used to expose information from modules.

---

5. TERRAFORM COMMANDS USED

---

terraform init

Initializes the Terraform working directory and installs required providers.

terraform fmt

Formats Terraform configuration files.

terraform validate

Checks whether the Terraform configuration is valid.

terraform plan

Shows the infrastructure changes Terraform intends to make.

terraform apply

Creates or updates the infrastructure.

8. PORT MAPPING

---

The Nginx container listens internally on port 80.

The host exposes it through port 8087.

Port mapping:

8087 -> 80

Therefore the application can be accessed using:

http://localhost:8087

---

10. KEY TAKEAWAY

---

terraform.tfvars provides values for input variables.

variables.tf defines the variables.

main.tf uses the variables to create infrastructure.

outputs.tf displays useful information after deployment.

This separation makes Terraform configurations cleaner, reusable and easier to maintain.
